# 1.5 Key Performance Indicators (KPIs)

## Product KPIs
| KPI | Target |
|-----|--------|
| Page response time (normal pages) | Under 3 seconds |
| Concurrent users supported | Up to 200 |
| MCQ exam result availability | Instantly after submission |
| Access after payment approval | Immediately after the admin approves |
| Payment request status visibility | Every request is Pending, Approved or Rejected and trackable |
| System availability | Application available during demo and evaluation |

## Project KPIs
| KPI | Target |
|-----|--------|
| Milestones delivered on time | All DEPI deadlines |
| Functional requirements implemented | All must-have requirements (FR-01 to FR-27) |
| Core services covered by unit tests | Payment approval, MCQ grading, total score |
| Pull Requests reviewed before merge | 100% |
| Documentation uploaded to GitHub | 100% of required items |
