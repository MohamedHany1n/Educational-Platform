# 3.1 Stakeholder Analysis

| Stakeholder | Role in the system | Main needs | Influence |
|-------------|-------------------|-----------|-----------|
| Admin | Manages the platform | Control users and courses, verify payments, see reports | High |
| Teacher | Publishes content and evaluates students | Easy course and exam creation, grading tools, see results | High |
| Student | Learns and takes exams | Browse courses, simple enrollment, watch lessons, see grades | High |
| Parent | Follows the child's progress | Clear view of progress and grades of linked children only | Medium |
| Project team | Builds the system | Clear requirements and scope | High |
| Lecturer / DEPI | Evaluates the project | Complete documentation and a working system | High |
