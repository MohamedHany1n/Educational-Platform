# 3.2 User Stories & Use Cases

Detailed use case diagram and descriptions: [Use Cases](../4-analysis-design/02-use-cases.md).

## Admin
- As an admin, I want to create and deactivate teacher and student accounts so that I control who uses the platform.
- As an admin, I want to approve or reject new student and parent registrations so that only real users can log in.
- As an admin, I want to see pending payment requests with the receipt image so that I can approve or reject them.
- As an admin, I want to view reports (users, enrollments, requests, revenue) so that I can follow the platform.

## Teacher
- As a teacher, I want to create a course with a title, description, price and thumbnail so that students can find it.
- As a teacher, I want to add and reorder lessons with video links so that students can study in order.
- As a teacher, I want to create exams with MCQ and essay questions so that I can evaluate students.
- As a teacher, I want to grade essay answers with feedback so that students know their results.

## Student
- As a student, I want to browse and search courses so that I can choose what to study.
- As a student, I want to submit a payment receipt for a course so that I can enroll.
- As a student, I want to watch lessons after approval so that I can learn.
- As a student, I want to take an exam within the time limit and see my grade so that I know my level.

## Parent
- As a parent, I want to link my account to my child so that I can follow them.
- As a parent, I want to see my child's progress and grades so that I know how they are doing.
